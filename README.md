# Планировщик задач

Дипломный проект — веб-сервер на Go, реализующий TODO-лист с повторяющимися задачами.

Позволяет добавлять, редактировать, удалять задачи и отмечать их как выполненные. Если задача периодическая, при выполнении она переносится на следующую дату.

## Задания со звёздочкой

- Переменная окружения `TODO_PORT` для порта
- Переменная окружения `TODO_DBFILE` для пути к БД
- Все правила повторения: `d`, `y`, `w`, `m`
- Поиск задач по строке и по дате
- Аутентификация по паролю (JWT)
- Dockerfile

## Как запустить

```
go run main.go
```

После этого открываем http://localhost:7540/ в браузере.

Можно задать переменные окружения:
- `TODO_PORT` — порт (по умолчанию 7540)
- `TODO_DBFILE` — путь к файлу БД (по умолчанию scheduler.db)
- `TODO_PASSWORD` — если задать, включится аутентификация

Пример:
```
TODO_PORT=8080 TODO_PASSWORD=mypass go run main.go
```

## Как запустить тесты

Сначала запускаем сервер, потом в другом терминале:

```
go test ./tests
```

В файле `tests/settings.go` можно настроить параметры:
- `FullNextDate = true` — тестировать все правила повторения
- `Search = true` — тестировать поиск
- `Token` — JWT-токен, если сервер запущен с `TODO_PASSWORD`

Чтобы получить токен, надо отправить POST на `/api/signin` с JSON `{"password":"ваш_пароль"}`.

## Docker

Сборка:
```
docker build -t todo-app .
```

Запуск:
```
docker run -p 7540:7540 -v $(pwd)/scheduler.db:/app/scheduler.db todo-app
```

Если нужен пароль, добавляем `-e TODO_PASSWORD=mypass`.
